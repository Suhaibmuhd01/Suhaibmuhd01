## About Me
Hi, I'm **Suhaib**, a software developer from Kano, Nigeria. I enjoy building software that solves real problems, whether that means simplifying an academic process, managing financial workflows, automating repetitive tasks, or creating a better experience for users.
I work across frontend and backend development, with an increasing focus on cross-platform mobile applications, API design, database integration, and maintainable application architecture.

Some of my projects are inspired by problems I have encountered in university environments and organizations. Others are opportunities to explore new ideas, build reusable tools, and improve my engineering skills.
I care about how software works behind the interface: how data is stored, how permissions are enforced, how workflows move from one stage to another, and how the application behaves when something goes wrong.

**What I'm working towards:** becoming a stronger software engineer who can take an idea from requirements and architecture through implementation, testing, and deployment.

- 📱 Building skills in cross-platform mobile development with React Native and Expo.
- 🌐 Developing web applications with React, Next.js, JavaScript, and TypeScript.
- ⚙️ Building backend services, REST APIs, authentication, and application workflows.
- 🗄️ Working with relational databases and backend platforms.
- 🔐 Learning and applying good practices in application security and data management.
- 🤝 Open to collaborative projects, useful open-source contributions, and software engineering opportunities.

## Selected Projects

These are some of the projects that best represent the kind of software I enjoy building: systems with meaningful workflows, practical use cases, and room for thoughtful engineering.

### 1. Course Allocation System

**Academic workload management and course allocation**

A system designed for the IT Department at Federal University Dutse to support the allocation of courses to lecturers. The project focuses on lecturer workloads, course data, allocation rules, conflict detection, and decision support to help make the allocation process more organized and consistent.

**Stack:** React · Tailwind CSS · Supabase · PostgreSQL

[Repository](https://github.com/Suhaibmuhd01/Course-Allocation-System)

### 2. ASUU Multipurpose Cooperative Management System

**Digital management for cooperative operations**

A cooperative management system designed around member records, savings, shares, loan applications, repayments, and financial transactions. Its approval workflow follows the responsibilities of the Secretary, Treasurer, and Chairman, with role-based access and clear stages for reviewing applications.

**Stack:** PHP · MySQL · JavaScript · REST APIs · Authentication and role-based access

[Repository](https://github.com/Suhaibmuhd01/fud-asuu-cooperative)

### 3. FUD-Pal

**A digital platform for the Federal University Dutse community**

FUD-Pal is a university-focused application intended to bring useful student services and academic information into one place. The project explores account management, academic features, student-focused workflows, and a more accessible way for users to interact with university services.

**Stack:** PHP · MySQL · Tailwind CSS · JavaScript

[Repository](https://github.com/Suhaibmuhd01/Fud-Pal)

### 4. Bright Path Initiative CMS

**A web platform with content and data management**

A platform developed for an initiative that needs a clear online presence and manageable content. The project combines a modern interface with database-backed functionality, with an emphasis on making information easier to maintain and present.

**Stack:** React · Tailwind CSS · Supabase

[Repository](https://github.com/Suhaibmuhd01/brightpathinitiative)

### 5. FarmConnect

**Agricultural marketplace and supply-chain platform**

A project developed for the OPay Scholars National Challenge, exploring how digital tools can connect agricultural products, buyers, and sellers. It brings together marketplace thinking, user-facing application design, and the foundations of a broader agricultural platform.

**Stack:** React · Mobile-focused development · Full-stack application technologies

[Repository](https://github.com/Suhaibmuhd01/FarmConnect)

### 6. DayniteJs

**A lightweight JavaScript theme utility**

DayniteJs is a reusable JavaScript library for switching between light and dark themes, retaining user preferences, and supporting Tailwind CSS workflows. It is one of my open-source projects and reflects my interest in building small, reusable tools that other developers can integrate into their applications.

**Stack:** JavaScript · TypeScript declarations · Rollup · Jest

[Repository](https://github.com/Suhaibmuhd01/DayniteJs)
